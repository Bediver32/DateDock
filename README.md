# Импорт файлов с устройства

Программа для Windows показывает файлы в папках устройства и копирует их на рабочий стол. Нужен Python 3 с Tkinter из стандартной установки Python для Windows.

## Запуск

Откройте PowerShell или терминал VS Code в папке репозитория:

```powershell
python .\photo_import.py
```

Если интерпретатор установлен в `C:\Python314`, можно указать его путь:

```powershell
& 'C:\Python314\python.exe' '.\photo_import.py'
```

## Импорт с устройства

1. Подключите устройство и выберите букву диска или метку тома. Программа покажет папки внутри `DCIM`. Папку также можно добавить вручную.
2. В таблице **Исходные папки** выберите одну или несколько папок. В таблице **Файлы по датам** появится количество файлов на каждую дату изменения.
3. Выберите нужные строки в таблице дат или нажмите **Все даты**. Нажмите **Импортировать**. Файлы скопируются на рабочий стол в **Фото с устройства**, в отдельные папки формата `дд.мм.гг`.

Для выбора нескольких строк удерживайте **Ctrl**. Кнопка **Обновить** перечитывает исходные и импортированные папки.

## Объединение импортированных папок

Справа всегда видны папки с отдельными датами и количество файлов в них. Выберите две или больше строк и нажмите **Объединить выбранные**. Имя новой папки отображается под таблицей до копирования.

Например, для `10.11.26` и `20.11.26` результатом будет `10-20.11.26`. Если месяцы или годы различаются, используются обе полные даты, например `20.11.26–01.12.26`. Итоговая папка находится рядом с исходными папками, которые сохраняются. Для объединения подключать устройство не нужно.

Кнопка **Открыть папку импорта** открывает папку **Фото с устройства** в Проводнике. При повторном копировании одинаковые файлы пропускаются. Если имена совпадают, а содержимое различается, новая копия получает суффикс `(2)`, `(3)` и так далее.
