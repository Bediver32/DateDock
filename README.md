# Импорт файлов с устройства

Программа на C++17 с графическим интерфейсом Windows. При подключении диска ищет в `DCIM` папку `PHOTO` с наибольшим номером и показывает доступные даты изменения файлов.

1. Введите букву диска (например, `E:`) или метку тома.
2. Укажите минимальный номер папки. По умолчанию — `110`.
3. Выберите одну или несколько дат и нажмите **Копировать на рабочий стол**.

Файлы сохраняются в папку **Фото с устройства** на рабочем столе, в подпапки формата `дд.мм.гг`. Повторный импорт пропускает одинаковые файлы.

## Сборка

В **Developer PowerShell for Visual Studio** с установленными компонентами C++ выполните из корня репозитория:

```powershell
cl /nologo /std:c++17 /EHsc /utf-8 /O2 /MT photo_import.cpp user32.lib gdi32.lib shell32.lib /link /SUBSYSTEM:WINDOWS
if ($LASTEXITCODE -eq 0) { .\photo_import.exe }
```

Для запуска собранного приложения Python не требуется.
