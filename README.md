# Импорт файлов с устройства

Программа для Windows копирует файлы с камеры или другого устройства, которое отображается в Проводнике как диск с буквой. В папке `DCIM` программа выбирает папку `PHOTO` с наибольшим номером и показывает доступные даты изменения файлов.

## Запуск

Нужен Python 3 с Tkinter. Tkinter входит в стандартную установку Python для Windows. Сторонние пакеты не нужны.

Откройте PowerShell или терминал VS Code в папке репозитория и выполните:

```powershell
python .\photo_import.py
```

Если Python установлен в `C:\Python314`, можно запустить его по полному пути:

```powershell
& 'C:\Python314\python.exe' '.\photo_import.py'
```

## Копирование

1. Подключите устройство. Выберите его в списке или введите букву диска (например, `E:`) либо метку тома.
2. Укажите минимальный номер папки. По умолчанию это `110`. Например, из `110PHOTO`, `112PHOTO` и `113PHOTO` программа выберет `113PHOTO`.
3. Выберите нужные даты. Для выбора нескольких дат удерживайте **Ctrl** или нажмите **Все даты**.
4. Нажмите **Копировать на рабочий стол**.

Копии появятся в папке **Фото с устройства** на рабочем столе, в подпапках вида `25.10.26` (`дд.мм.гг`). Программа создаёт подпапки только для файлов, которые удалось скопировать. При повторном импорте одинаковые файлы пропускаются. Если имя совпадает, а содержимое различается, новая копия получает суффикс `(2)`, `(3)` и так далее. Исходные файлы остаются на устройстве.
