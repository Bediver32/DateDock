# Импорт файлов с устройства

Программа для Windows показывает файлы в папках устройства и копирует их на рабочий стол. Нужен Python 3 с Tkinter из стандартной установки Python для Windows.

## Запуск

Откройте PowerShell или терминал VS Code в папке репозитория:

```powershell
python .\photo_import.py
```

Если интерпретатор установлен в `C:\Python314`, можно указать его путь:

```powershell
& 'C:\Python314\python.exe' '.\photo_import.py'
```

## Выбор файлов

1. Подключите устройство. Выберите букву или метку тома в поле **Диск**. Программа покажет папки внутри `DCIM`.
2. Выберите нужные папки слева. Используйте **Ctrl** для выбора нескольких папок или нажмите **Выбрать все папки**. Кнопка **Добавить папку…** позволяет добавить любую папку вручную.
3. Справа появятся файлы из выбранных папок, включая фото и видео. Оставьте **Все даты** или выберите одну дату изменения файла. Обе операции копируют файлы, показанные в таблице.

## Импорт и объединение

- **Импортировать по датам** копирует файлы в отдельные папки формата `дд.мм.гг`.
- **Объединить папки** копирует файлы из нескольких выбранных папок в одну. Название содержит самую раннюю и самую позднюю дату изменения. Для одного месяца это, например, `10-20.11.26`, а для разных месяцев — `20.11.26–01.12.26`. Для одного дня используется одна дата.

Результат сохраняется на рабочем столе в папке **Фото с устройства**. Кнопка **Открыть папку импорта** открывает её в Проводнике. Исходные файлы остаются на месте. При повторном импорте одинаковые файлы пропускаются. Если имена совпали, а содержимое различается, новая копия получает суффикс `(2)`, `(3)` и так далее.
