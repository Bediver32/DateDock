# DateDock

<img src="datedock.png" width="112" alt="Логотип DateDock">

DateDock импортирует файлы с устройства на Windows и раскладывает их по папкам с датами. Перед копированием можно объединить строки в очереди.

## Запуск

Откройте папку репозитория в Проводнике и дважды щёлкните **DateDock.cmd**. Для работы нужен установленный Python 3 с Tkinter.

Чтобы запускать DateDock с рабочего стола, щёлкните правой кнопкой по `DateDock.cmd` и выберите **Отправить → Рабочий стол (создать ярлык)**. В Windows 11 этот пункт может находиться в **Показать дополнительные параметры**. Для значка DateDock откройте свойства ярлыка, нажмите **Сменить значок…** и выберите `datedock.ico` из папки программы.

## Как подготовить импорт

1. На вкладке **С устройства** выберите диск или вставьте путь в поле **Путь к исходной папке** и нажмите **Добавить** либо **Enter**. Кнопка **Обзор…** открывает выбор папки. Затем выберите исходные папки и нужные даты. На вкладке **Папки на рабочем столе** можно выбрать уже импортированные папки с датами.
2. Нажмите **В очередь**. Справа, в разделе **2. К импорту · предпросмотр**, появятся отдельные строки с названиями папок и количеством файлов. Даты и диапазоны отсортированы от ранних к поздним.
3. Чтобы объединить папки, выделите две или больше строк в предпросмотре с помощью **Ctrl** и нажмите **Объединить выбранные**. Выбранные строки заменит одна строка с диапазоном дат. Например, из `10.11.26` и `20.11.26` получится `10-20.11.26`. Если месяцы или годы различаются, программа покажет обе даты полностью.

Чтобы исключить строки, выделите их и нажмите **Убрать из очереди**.

## Как запустить копирование

Нажмите **Импортировать очередь**. Только после этого программа обработает строки из предпросмотра. Результат сохраняется на рабочем столе в папке **Фото с устройства**. Исходные папки сохраняются. Для объединения папок на рабочем столе подключать устройство не нужно.

После успешного импорта очередь очищается. При ошибке она остаётся для повторной попытки. При повторном копировании одинаковые файлы пропускаются, а при совпадении имён файлы с разным содержимым получают суффикс `(2)`, `(3)` и так далее.
