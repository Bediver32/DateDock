# Импорт файлов с устройства

Программа для Windows показывает файлы в папках устройства и копирует их на рабочий стол. Нужен Python 3 с Tkinter из стандартной установки Python для Windows.

## Запуск

Откройте PowerShell или терминал VS Code в папке репозитория:

```powershell
python .\photo_import.py
```

Если интерпретатор установлен в `C:\Python314`, можно указать его путь:

```powershell
& 'C:\Python314\python.exe' '.\photo_import.py'
```

## Как подготовить импорт

- **С устройства.** Выберите диск или добавьте папку вручную. Выберите исходные папки и нужные даты. В таблице рядом с каждой датой показано количество файлов. Нажмите **В очередь**.
- **Папки на рабочем столе.** Откройте эту вкладку, выберите две или больше уже импортированных папок с датами и нажмите **Объединить в очереди**. Например, для `10.11.26` и `20.11.26` в предпросмотре появится папка `10-20.11.26`. Для разных месяцев или лет показываются обе даты полностью.

Для выбора нескольких строк удерживайте **Ctrl**. Объединение можно подготовить при отключённом устройстве.

## Как запустить копирование

Справа, в разделе **К импорту · предпросмотр**, показаны будущие папки и количество файлов в каждой. Чтобы исключить папку, выберите её и нажмите **Убрать из очереди**.

Копирование начинается после нажатия **Импортировать очередь**. Программа обрабатывает только строки из предпросмотра. Результат сохраняется на рабочем столе в папке **Фото с устройства**. Исходные папки сохраняются.

После успешного импорта очередь очищается. При ошибке она остаётся для повторной попытки. При повторном копировании одинаковые файлы пропускаются, а при совпадении имён файлы с разным содержимым получают суффикс `(2)`, `(3)` и так далее.
