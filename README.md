# Импорт файлов с устройства

Программа для Windows показывает файлы в папках устройства и копирует их на рабочий стол. Нужен Python 3 с Tkinter из стандартной установки Python для Windows.

## Запуск

Откройте PowerShell или терминал VS Code в папке репозитория:

```powershell
python .\photo_import.py
```

Если интерпретатор установлен в `C:\Python314`, можно указать его путь:

```powershell
& 'C:\Python314\python.exe' '.\photo_import.py'
```

## Выбор файлов

1. Подключите устройство. Выберите букву или метку тома в поле **Диск**. Программа покажет папки внутри `DCIM`.
2. Выберите нужные папки слева. Используйте **Ctrl** для выбора нескольких папок или нажмите **Выбрать все папки**. Кнопка **Добавить папку…** позволяет добавить любую папку вручную.
3. Справа появятся файлы из выбранных папок, включая фото и видео. Оставьте **Все даты** или выберите одну дату изменения файла.
4. Нажмите **Импортировать по датам**. Файлы из таблицы будут скопированы на рабочий стол в **Фото с устройства**, в отдельные папки формата `дд.мм.гг`.

## Объединение импортированных папок

1. Нажмите **Объединить папки по датам…**. Откроется список папок с отдельными датами в папке **Фото с устройства**.
2. Выберите две или больше папок с помощью **Ctrl** и проверьте имя итоговой папки.
3. Нажмите **Объединить**.

Итоговое имя берётся из названий выбранных папок. Например, `10.11.26` и `20.11.26` объединятся в `10-20.11.26`. Для разных месяцев используется полная запись обеих дат, например `20.11.26–01.12.26`. Подключённый диск для объединения не требуется. Исходные папки сохраняются.

Кнопка **Открыть папку импорта** открывает папку **Фото с устройства** в Проводнике. При повторном копировании одинаковые файлы пропускаются. Если имена совпадают, а содержимое различается, новая копия получает суффикс `(2)`, `(3)` и так далее.
