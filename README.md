# Импорт файлов с устройства

Программа на Python для Windows. При подключении диска ищет в `DCIM` папку `PHOTO` с наибольшим номером и показывает даты изменения файлов.

## Запуск

В PowerShell из папки репозитория:

```powershell
& 'C:\Python314\python.exe' '.\photo_import.py'
```

Если Python установлен в другом месте, укажите путь к своему интерпретатору. Используется Tkinter из стандартной поставки Python для Windows. Сторонние пакеты не нужны.

В VS Code также можно нажать **F5** и выбрать **Photo Import (Python)**. Для этого нужны расширения **Python** и **Python Debugger** от Microsoft и выбранный интерпретатор Python.

## Импорт

1. Введите букву диска (по умолчанию `E:`) или его метку. Можно выбрать диск из списка.
2. Укажите минимальный номер папки. По умолчанию — `110`.
3. Выберите одну или несколько дат и нажмите **Копировать на рабочий стол**.

Файлы копируются в **Фото с устройства** на рабочем столе, в подпапки формата `дд.мм.гг`. Программа пропускает одинаковые файлы при повторном импорте и создаёт подпапку даты только при копировании файла.

Исходник предыдущей C++-версии и её сценарий сборки сохранены в репозитории.
